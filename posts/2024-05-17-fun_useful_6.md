自己是一个很喜欢尝试新软件、探索新网站的人，这个系列文章，把自己觉得有趣的玩意，或者能提高效率的工具汇总起来，分享给大家。

### 朋友圈转发截图生成工具

[https://akarin.dev/WechatMomentScreenshot/](https://akarin.dev/WechatMomentScreenshot/)

![朋友圈转发截图生成工具](https://s21.ax1x.com/2024/07/01/pkgApZ9.png)

现在许多商家推出在朋友圈转发广告就减免的营销活动，作为消费者的我们，一方面不愿发朋友圈打扰好友，或者不想朋友圈带上生活之外的内容，另一方面又迫于钱包的压力想要节省零头。这个网站很好地解决了这个窘境，将自己的微信头像和想要发布的内容上传至该网站，设置需要点赞的数量，就可以生成商家想要的集赞截图了。

关键词：朋友圈，点赞，工具


### GoodUI - 经过AB测试成功的UI设计案例

[https://goodui.org/](https://goodui.org/)

![GoodUI官网](https://s21.ax1x.com/2024/07/01/pkgAZse.png)

对一款App来讲，视觉UI的设计至关重要，好看且合理的UI会提高用户体验，促进实现产品目标。这篇网站收集了各类业务产品、各种功能模块下，不同UI方案在AB试验下对应业务指标的变化。适合UI设计师、产品经理从UI角度挖掘提升业务指标的idea。

关键词：设计，UI，创意


### FreeReNamer - 文件批量重命名工具

[https://github.com/cyhuajuan/FreeReNamer](https://github.com/cyhuajuan/FreeReNamer)

![ReNamer使用界面](https://s21.ax1x.com/2024/07/01/pkgZpZQ.png)

这款开源软件是一款支持批量更改文件名的工具，支持按照各种规则给文件重新命名，包括添加统一前后缀、首字母大写、删除某个特征文本等等。支持多平台，同时也有网页端，直接在浏览器就能完成操作。整理控必备。

关键词：效率，工具，整理


### 海豚配音 - 在线TTS文字转语音

[https://www.ttson.cn/](https://www.ttson.cn/)

![海豚配音官网](https://s21.ax1x.com/2024/07/01/pkgkO2T.png)

现在TTS技术已经非常成熟了，视频的许多声音效果，甚至是整段视频解说都采用AI生成的人声。这个网站提供了TTS人声生成的服务，只需要输入一段文字，即可生成对应的AI人声，很方便并且效果还不错。此外，网站还提供多种不同声音风格，以适配不同的使用场景。

关键词：人工智能，TTS


### 网页生成epub电子书的chrome插件

[https://github.com/sunxen/EpubPressX](https://github.com/sunxen/EpubPressX)

![插件使用截图](https://github.com/sunxen/EpubPressX/raw/master/screenshots/4.png)

我自己有将稍后阅读的文章批量生成一个epub文件，然后发送到kindle的阅读的习惯。这个chrome插件可以很方便实现这个过程，其支持将网页转换为epub电子书格式，同时插件也可以将多个打开标签页合并至一个epub文件。实测下来，生成速度挺快的，轻量且好用。

关键词：阅读，电子书，epub


### Shields.io - Github 徽章制作

[https://github.com/badges/shields](https://github.com/badges/shields)

![Shields.io Github repo](https://s21.ax1x.com/2024/07/01/pkgA1Rf.png)

在浏览 Github 时，经常碰到一些高大上的项目会在readme.md说明顶端加上各类徽章，久而久之，这些徽章似乎会使得人们潜意识离感觉repo更加专业。这个项目提供了Github repo徽章制作的工具，在上面，我们可以很方便地自定义徽章样式，并通过url直接插入到我们readme.md文件以图片形式显示。

关键词：Github，设计


### 壁纸样机生成器

[https://mjcn.club/](https://mjcn.club/)

![壁纸样机生成器使用界面](https://s21.ax1x.com/2024/06/17/pk0GsdH.png)

这个网站提供了演示壁纸实际上机效果的工具。上传一张壁纸，就可以为你生成壁纸在手机中实际显示的效果，配合各类背景，可以轻松制作出一张壁纸宣传图。网站内壁纸效果样式丰富，并且高度定制化，各种场景（锁屏界面，主界面…），各种设备（iPhone，iPad…）等皆可自定义调节。喜欢制作壁纸的朋友可以尝试一下。

关键词：壁纸，设计


### vCards 中国黄页

[https://github.com/metowolf/vCards](https://github.com/metowolf/vCards)

![中国黄页通讯录](https://user-images.githubusercontent.com/2666735/59692672-0b6bdf00-9218-11e9-881e-5856e263f3aa.png)

该Github repo收集了中国大大小小部门与公司的电话与logo，导入手机通讯录后，可以优化接到相关电话和短信的体验。

关键词：通讯录


### No-Bullshit Games - 好玩的手机游戏列表

[https://nobsgames.stavros.io/](https://nobsgames.stavros.io/)

![No-Bullshit Games 官网](https://s21.ax1x.com/2024/06/17/pk0GURx.png)

大屏手机刚发布的年代，印象中的手机游戏都比较纯粹，小巧但兼具创意和趣味，例如《水果忍者》《Temple Run》《Cut The Role》等。手机普及后的手游更多是商业化产品，要么需要氪金才能成为大佬，要么广告多得无法忍受。这个网站帮大家过滤了难玩的手游，收录了经典好玩的游戏，囊括ios、安卓两大平台，喜欢在手机平台的玩家一定不要错过。

关键词：游戏，娱乐


### SnapAny - 万能视频图片解析下载

[https://snapany.com/zh](https://snapany.com/zh)

![SnapAny网站首页](https://s21.ax1x.com/2024/06/20/pkDVogH.png)

如果你想下载正在浏览的某个视频，可以尝试访问这个网站，输入视频网址或者分享链接，网站会自动解析视频源，生成下载链接，使用起来非常方便。网站集中支持了很多视频、图片等资源平台，包括主流的Bilibili、抖音、Youtube，以及最新发布的Suno AI音乐平台等。建议放入收藏夹以备不时之需。

关键词：工具，下载，视频
